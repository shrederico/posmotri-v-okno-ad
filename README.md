# Посмотри в окно

Учебный проект Яндекс Практикума: оформление приложения для поиска и просмотра видео из разных городов.

## Ссылка на репозиторий

https://github.com/shrederico/posmotri-v-okno-ad

## Технологии

HTML, CSS, JavaScript. Раскладка на Flexbox, кастомные чекбоксы, состояния интерактивных элементов и прокручиваемый список карточек.

## Запуск

Откройте папку проекта в VS Code и запустите index.html через Live Server. Установка зависимостей и сборка не требуются.

Видео и данные загружаются с внешнего сервера Практикума. Для работы поиска и воспроизведения необходим доступ к этому серверу.
